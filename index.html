About

Curiosity first.

I care about the full picture: how an interface feels, how the system works underneath, and what happens when someone uses it.

I’m a Computer Science student working across mobile and web development, backend integration and computer-vision research. I test ideas, improve the small details, and keep my repositories honest about what is finished and what is still in progress.

Security belongs in the build, not just at the end. I’m drawn to defensive thinking, safe and authorized experimentation, and documentation that explains both the issue and the fix.

Good work starts with a question.

Have a project idea, a useful resource or a different way to solve a problem? I’m glad to connect, learn and trade ideas. GitHub is where I’m most active.
